# 赛事更新计划

这份文档用于记录所有已经录入、仍然需要持续更新的赛事和团队奖项。

规则只有两类：

- **现行赛事**只进入 `1月更新批次` 或 `7月更新批次`。
- **停办赛事**只做登记，不进入固定批次，后续仅在补漏或纠错时处理。

以后每次新增现行赛事时，都必须同步更新这份文档。

## 更新执行顺序

每次按批次更新时，建议按下面顺序处理：

1. 赛事结果。
2. 缺失俱乐部 / 国家补齐。
3. 团队奖项。
4. 荣誉分重算。
5. 页面抽查。

## 配套约定

- 以后新增现行赛事时，必须同时加入 `1月更新批次` 或 `7月更新批次`。
- 如果新增的是停办赛事，只加入“停办赛事登记”。
- 如果赛事状态从现行改为停办，需要从固定批次移到停办登记。
- 如果某次固定批次没有更新完，允许顺延到下一批，不新增临时更新窗口。
- 这份文档只负责“什么时候更、这一批更什么”，不替代赛事规则文档。
