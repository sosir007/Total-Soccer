# 赛事更新计划

这份文档用于记录所有已经录入、仍然需要持续更新的赛事和团队奖项。

规则只有两类：

- **现行赛事**只进入 `1月更新批次` 或 `7月更新批次`。
- **停办赛事**只做登记，不进入固定批次，后续仅在补漏或纠错时处理。

以后每次新增现行赛事时，都必须同步更新这份文档。

## 数据完整性字段

赛事和奖项都维护以下字段：

| 字段 | 含义 | 初始标记规则 |
| --- | --- | --- |
| 是否录入完整 | 当前库内荣誉数据是否按项目口径完整 | 未系统核对前统一标 `否`；核对完成后再改 `是` |
| 数据更新时间 | 最近一次系统核对或批量补录荣誉数据的日期 | 未系统核对前为空；完成批量核对后填写当天日期 |
| 完整性备注 | 只记录数据口径、例外项或少量缺失项 | 没有特殊情况可以留空；非标准对象可备注后仍标完整 |

完整性只按当前项目口径判断，不代表全球足球资料库的无限制全量口径。例：博览会杯的伦敦联队是城市代表队，不作为普通俱乐部入库，备注说明后仍可标为完整。

## 更新执行顺序

每次按批次更新时，建议按下面顺序处理：

1. 赛事结果。
2. 缺失俱乐部 / 国家补齐。
3. 团队奖项。
4. 荣誉分重算。
5. 页面抽查。

## 配套约定

- 以后新增现行赛事时，必须同时加入 `1月更新批次` 或 `7月更新批次`。
- 如果新增的是停办赛事，只加入“停办赛事登记”。
- 如果赛事状态从现行改为停办，需要从固定批次移到停办登记。
- 如果某次固定批次没有更新完，允许顺延到下一批，不新增临时更新窗口。
- 这份文档只负责“什么时候更、这一批更什么”，不替代赛事规则文档。
