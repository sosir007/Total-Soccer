# 马拉多纳奖项成就临时清单

> 临时核对文档。用于后续录入马拉多纳个人奖项和个人成就，不直接代表已经入库。

## 口径说明

- 本文只整理个人奖项、个人榜单、个人成就；俱乐部和国家队奖杯另走“关联团队荣誉”。
- 阿根廷 U20 的 `1979 世青赛冠军` 不列入本文；但 `1979 世青赛金球奖 / 银靴奖` 属于个人奖项，可以作为候选录入。
- 后续真正入库时，优先匹配系统已有 `Award`、`AwardEdition`、`CompetitionEdition`；匹配不上先不录，单独反馈缺口。
- `国际足联世界杯金球奖` 仍沿用系统既有特殊展示口径：第一名为金球奖，第二名为银球奖，第三名为铜球奖。
- 南美足球先生存在 `El Mundo` 和 `El País` 两套口径。马拉多纳 1979、1980、1986、1989、1990、1992 这一组按旧 `El Mundo` 口径整理，后续不要和 `El País` 年度前三混录。

## 勾选说明

- `☐` 表示待录入。
- `☑` 表示已录入。
- 你后面真正入库时，只需要把对应行的 `录入` 列改成 `☑`。

## 暂不建议录入

| 各类“史上最佳球员榜单”普通媒体排名 | 容易膨胀且重复，除非来自 FIFA、France Football、IFFHS、World Soccer 等高权威来源。 |

| 纯纪录类条目 | 例如某赛事最年轻、某俱乐部历史数据纪录，后续如果做纪录模块再维护。 |
| 世界杯助攻榜第一 | FIFA 有助攻统计榜，1986 马拉多纳 5 次助攻无争议；但没有看到正式“世界杯助攻王”奖杯或奖项目录，先不作为个人奖项计分。 |

## 后续入库检查顺序

1. 先查系统是否已有 `SOUTH_AMERICAN_FOOTBALLER_OF_THE_YEAR`、`FIFA_WORLD_CUP_GOLDEN_BALL` 等奖项本体。
2. 对赛事内奖项，先确认赛事届次存在，例如 `1986` 世界杯、`1979 Nacional` 阿甲、`1987-88` 意甲。
3. 对没有奖项本体的项目，先补奖项规则，再录 `AwardRecipient`。
4. 对 `Olimpia de Oro`、`金球奖特别荣誉奖`、`FIFA 世纪最佳进球` 这类非标准年度竞技奖，优先走 `PlayerHonor`。
5. 录完后重算球员奖项分，核对奖项数、顶级奖项数、成就分和荣誉清单展示。
